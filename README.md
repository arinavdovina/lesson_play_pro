# Lesson Play — мастерская учебных игр

Готовый статический сайт: сборка, Node.js, серверная база и API-ключи не нужны.

## Открыть на компьютере

Распакуйте архив и откройте `index.html` в Chrome, Edge или Safari. Не переносите index.html отдельно: рядом должны остаться остальные файлы и папки.

## Выложить на GitHub Pages

1. Создайте репозиторий `lesson-play` в своём GitHub.
2. Загрузите **содержимое** папки `lesson-play` в корень репозитория. В корне должен оказаться `index.html`, а не ZIP-архив и не ещё одна папка lesson-play.
3. Сохраните изменения (Commit changes). При большом количестве файлов загружайте их партиями или используйте GitHub Desktop. Сохраняйте структуру assets/ и originals/.
4. Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, затем ветку main и папку / (root), нажмите Save.
5. Дождитесь ссылки на сайт в разделе Pages. Адрес обычно имеет вид https://ВАШ-ЛОГИН.github.io/lesson-play/.

Для обычного бесплатного размещения используйте публичный репозиторий. Это инструкция для самостоятельной публикации: сайт от вашего имени не опубликован.

## Как пользоваться

1. **Урок:** укажите язык, уровень, возраст, тему, лексику и необязательную грамматику.
2. **Визуал:** выберите один из 19 наборов или добавьте свой фон и персонажа (PNG/JPG/WebP до 5 МБ). В раскрывающемся списке картинок можно выбрать любого персонажа из набора.
3. **Задания:** введите вопросы, используйте кнопку «Из лексики» или подготовьте вопросы через промпт для ИИ.
4. Проверьте игру кнопкой «Играть» и скачайте её кнопкой «Скачать игру».

### Из лексики

Каждая пара на отдельной строке:

```
snow — снег
gift — подарок
winter — зима
```

Нужно минимум две пары с разными переводами. Кнопка «Из лексики» создаёт задания на соответствие слов и переводов. Она не генерирует грамматические упражнения и не изменяет сложность автоматически.

### Вручную

```
I ___ happy. | am | is | are
They ___ friends. | are | am | is
```

Первый ответ после | — правильный; следующие — неверные. В игре порядок вариантов перемешивается. От 1 до 40 вопросов, от 2 до 4 вариантов. Для режима «Найди пару» достаточно вопроса и одного ответа, максимум 12 пар. Не используйте | внутри самих вопросов и ответов.

### Через ИИ

«Собрать промпт» учитывает язык, уровень, возраст, тему, лексику, грамматику и игровую механику. Скопируйте промпт в любой ИИ-чат, затем вставьте JSON-ответ в «Ответ ИИ» и нажмите «Применить задания».

Сайт **не подключён к ИИ автоматически**. API-ключи не нужны. Поля уровня, возраста и грамматики влияют на промпт; готовые задания необходимо проверить учителю.

### Сохранение и обмен

- **Скачать игру:** самостоятельный HTML-файл со встроенными картинками, который работает без интернета. Ученик скачивает файл и открывает в браузере. Некоторые мессенджеры не запускают HTML в собственном просмотрщике — файл следует открыть отдельно.
- **Сохранить проект:** JSON с настройками, заданиями и картинками. Загрузите через «Открыть проект», чтобы продолжить редактирование.
- Автосохранения и облачного хранения нет. Перед закрытием вкладки сохраните проект.
- Сайт не хранит API-ключи, не загружает ваши картинки на сервер и не собирает результаты учеников.

## Что внутри

- `index.html` — конструктор и библиотека.
- `style.css` — адаптивное оформление.
- `app.js` — редактор, промпт, импорт, экспорт.
- `game.js` — автономный игровой движок: викторина, прыжки, пары.
- `catalog.js` — каталог 19 визуальных наборов и 14 исходных HTML-игр.
- `assets/` — 175 оптимизированных изображений из предоставленных папок, включая вложенные наборы «Игры в кальмара».
- `assets-data.js` — встроенные изображения для сохранения автономных игр даже при открытии сайта через file://. Этот файл нужен вместе с assets/.
- `originals/` — копии исходных HTML-игр. Там, где удалось сопоставить картинки, ссылки заменены локальными. Оригиналы не становятся редактируемыми шаблонами конструктора; у них собственные правила и фиксированный учебный материал. Некоторые используют внешние изображения и требуют интернет.
- `.nojekyll` — файл для размещения статического сайта на GitHub Pages.

В отдельном архиве «Все исходные игры.zip» сохранены все предоставленные папки и оба корневых HTML-файла в первоначальном виде, без оптимизации картинок и без изменения кода. Его не обязательно загружать на сайт.

## Проверка

В браузере проверены запуск, правильные и неправильные ответы, результаты викторины, полный цикл поиска пар, создание промпта, импорт JSON, скачивание HTML и сохранение проекта. Скачанный HTML открыт отдельно от конструктора. Логика прыжков, начисления баллов, повторного старта и сброса карточек дополнительно проверена локально.

Исходные игры в библиотеке сохранены для доступа к вашей коллекции; полный игровой цикл каждой из 14 оригинальных игр не проверялся.
